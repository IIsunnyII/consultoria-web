# Portafolio — Astro + Tailwind CSS v4

Portafolio personal de ingeniería de software y desarrollo indie de videojuegos.
Sistema de diseño monocromo documentado en [DESIGN.md](DESIGN.md).

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # genera ./dist
```

Contenido editable en `src/data/` (`site.ts`, `projects.ts`, `stack.ts`).
